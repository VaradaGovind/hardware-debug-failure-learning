# Dataset and benchmark artifacts

The local `datasets/` tree contains benchmark metadata used by the experiments. Held-out labels, waveform traces, RTL fixtures, and generated benchmark files are not included in the initial Git history because their ownership and redistribution terms have not been established.

Before sharing any dataset or result outside the private research group, verify:

- whether the benchmark is synthetic or derived from proprietary material;
- whether redistribution is allowed;
- whether labels, logs, signal names, or paths reveal sensitive information;
- whether the exact simulator and benchmark-generation inputs can be shared.

If redistribution is not clearly permitted, provide a documented acquisition or regeneration procedure instead of committing the artifact.
